The skill is further informed by iterative image feedback on realism, editing, and Vietnamese storytelling. Prior discussions contained **206 initially collected rules plus 65 proposed additions (271 numbered notes)**; these were overlapping draft notes, not independently verified requirements. This skill merges them into a smaller, actionable workflow, with exceptions separated into project profiles.
